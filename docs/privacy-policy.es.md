# Política de privacidad

Esta página trata sobre el programa Nib y este sitio web. Nib es un programa de línea de comandos que se ejecuta en tu equipo.

## El programa

- Nib no tiene telemetría ni analítica.
- Envía tus prompts y los resultados de las herramientas al proveedor de modelos que elijas. A lo que este recibe se aplican sus propios términos y su política de privacidad.
- Puede contactar con integraciones que tú configures o invoques, como la búsqueda web, servidores MCP, hooks o notificaciones.
- Las claves de API se guardan en tu equipo en un archivo que solo tú puedes leer (permisos 0600).

## Este sitio web

- Las páginas no cargan scripts de analítica, publicidad ni de terceros, y no establecen cookies.
- Como cualquier servidor web, el nuestro y su CDN procesan metadatos de las peticiones, como tu dirección IP y tu navegador, para servir las páginas y proteger el sitio.
