# Privacy policy

This page covers the Nib program and this website. Nib is a command-line program that runs on your machine.

## The program

- Nib has no telemetry or analytics.
- It sends your prompts and tool results to the model provider you select. That provider's own terms and privacy policy apply to what it receives.
- It may contact integrations you configure or invoke yourself, such as web search, MCP servers, hooks or notifications.
- API keys are stored on your machine in a file readable only by you (mode 0600).

## This website

- The pages load no analytics, advertising or third-party scripts, and set no cookies.
- Like any web server, ours and its CDN process request metadata such as your IP address and browser, to deliver pages and to protect the site.
